Paired tablets

    Macro pad buttons

    Action types and key names

    Keys presses a shortcut, e.g. ctrl+shift+t, super+ctrl+down, f5, print, playpause. Keys: letters, digits, f1–f16, ctrl shift alt super, enter esc tab space backspace delete insert home end pageup pagedown up down left right print, and punctuation like minus comma period slash.

    Run runs a command, e.g. code ~/projects/game or flatpak run org.godotengine.Godot.

    Open opens a website, folder or file, e.g. https://github.com or ~/Downloads.

    Type types some text into the focused window.

    Game Dev Panel

    Send control changes to your game on UDP port
    Each change arrives as one JSON message, e.g. {"name":"speed","value":3.5}, sent to 127.0.0.1. The README has a ready-made Godot listener.
